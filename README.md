# Промпт как скальпель

Домашнее задание по лекции 3 «Проектирование промптов как искусство диалога с ИИ» (курс «Письмо и мышление», к.ф.н. Головко С. Б.).

Авторы: Тарасов Сергей, Иванова Софья, Остапенко Юлия.

- `index.html` — лендинг с плавной прокруткой (стрелки ↑↓ листают разделы, `F` разворачивает таблицу).
- `deck.html` — статичная версия на 16 слайдов 1920×1080 (из неё собраны PDF и PPTX).

Статический сайт без сборки, деплоится на Vercel как есть.
